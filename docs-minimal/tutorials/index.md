# Tutorials

Step-by-step guides that build on each other. Start from the top if you're new to Isaac Lab.

| Tutorial | What you'll learn | Time |
|----------|------------------|------|
| [Simulation Basics](simulation-basics.md) | Launch the simulator, spawn objects, run physics | 10 min |
| [Working with Assets](assets.md) | Rigid bodies, articulated robots, deformable objects | 15 min |
| [Interactive Scenes](scenes.md) | Multi-entity scenes with environment cloning | 10 min |
| [Building Environments](environments.md) | Create RL environments (manager-based and direct) | 20 min |
| [Using Sensors](sensors.md) | Cameras, ray casters, contact sensors | 15 min |
| [Motion Controllers](controllers.md) | Differential IK, operational space control | 10 min |

All tutorial scripts are in `scripts/tutorials/` and can be run with:

```bash
./isaaclab.sh -p scripts/tutorials/<category>/<script>.py
```
