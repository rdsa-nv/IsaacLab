**Bipedal locomotion with the Unitree G1 humanoid.**

## Quick start

```bash
# Train on flat terrain (~1 hr)
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py \
  --task Isaac-Velocity-Flat-G1-v0 --num_envs 4096

# Evaluate
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/play.py \
  --task Isaac-Velocity-Flat-G1-v0 --num_envs 32
```
