# Unitree H1 Humanoid

**Bipedal locomotion velocity tracking with the Unitree H1 humanoid robot.**

## Quick start

```bash
# Train on flat terrain (~1 hr)
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py \
  --task Isaac-Velocity-Flat-H1-v0 --num_envs 4096

# Evaluate
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/play.py \
  --task Isaac-Velocity-Flat-H1-v0 --num_envs 32

# Record video
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/play.py \
  --task Isaac-Velocity-Flat-H1-v0 --num_envs 32 --video
```

## Environment variants

| Task ID | Terrain |
|---------|---------|
